# Trabajo Práctico Nº 3 - Computación III: Portfolio Digital

## Descripción del Trabajo
Este proyecto consiste en el desarrollo e implementación de un portfolio digital personal con estética gaming y temática de videojuego RPG / Cyberpunk. A través de este sistema, se presentan los proyectos académicos e individuales organizados en diferentes secciones:

* **Inicio (`index.html`):** Presentación principal del servidor/sistema.
* **Nueva Aventura (`personaje.html`):** Creación y personalización de avatar.
* **Perfil (`cv.html`):** Hoja de vida y competencias técnicas.
* **Inventario (`inventario.html`):** Galería interactiva de proyectos con ventanas modales puras en CSS para inspeccionar estadísticas y detalles de cada ítem.
* **Opciones (`opciones.html`):** Ajustes multimedia (cinemática stop-motion) y formulario para soporte y contacto.

## Herramientas a utilizar:
Visual Studio Code (Editor de código) y Figma (Diseño y Maquetación).

### Resolución de pantalla a utilizar: 
1920 x 1080 px (Full HD)

### Tipografías y Arquitectura:
* **Estructura:** Arquitectura basada en HTML5 semántico y CSS3.
* **Fuentes:** Orbitron y Open Sans (Google Fonts).

### Colores utilizados:
Se implementó una paleta de colores oscuros para generar inmersión, con acentos neón en Cian (`#00FFCC`) y Naranja (`#CF6E24`) para interfaces, botones y textos clave.
